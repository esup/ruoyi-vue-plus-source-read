## 3. 模块职责详解

### 3.1 ruoyi-admin — 主启动模块

项目的HTTP入口，负责：

- **启动引导**: `DromaraApplication` 为Spring Boot主启动类
- **认证登录**: `AuthController` 提供登录/注册/获取用户信息等接口
- **验证码**: `CaptchaController` 支持数学计算/字符验证码
- **登录策略**: 通过 `IAuthStrategy` 接口实现多种登录方式
  - `PasswordAuthStrategy` — 账号密码登录
  - `SmsAuthStrategy` — 短信验证码登录
  - `EmailAuthStrategy` — 邮箱验证码登录
  - `SocialAuthStrategy` — 第三方社交登录
  - `XcxAuthStrategy` — 小程序登录
- **登录服务**: `SysLoginService` / `SysRegisterService` 处理登录校验、密码错误锁定等逻辑
- **用户行为监听**: `UserActionListener` 记录用户在线状态
- **国际化**: `i18n/` 目录下支持中文/英文多语言

### 3.2 ruoyi-common — 通用模块

采用 **插件化 + 扩展包** 设计，每个子模块独立职责，按需引入：

| 模块 | 核心职责 |
|------|---------|
| **common-core** | 全局常量、枚举、异常体系、通用DTO、LoginUser模型、线程池配置、Validation配置 |
| **common-mybatis** | MyBatis-Plus全局配置、分页插件、数据权限插件、多租户插件、逻辑删除、雪花ID主键策略 |
| **common-redis** | Redisson客户端配置、Spring Cache扩展(支持过期时间/最大空闲/组最大长度)、分布式队列 |
| **common-satoken** | Sa-Token集成、JWT令牌、权限校验注解、Token鉴权逻辑 |
| **common-security** | 安全基础模块，结合Sa-Token实现请求过滤与鉴权 |
| **common-tenant** | 多租户核心逻辑，基于MyBatis-Plus插件实现租户数据隔离，配置排除表 |
| **common-encrypt** | 数据加解密，注解+MyBatis拦截器实现自动加解密，支持BASE64/AES/RSA/SM2/SM4 |
| **common-sensitive** | 数据脱敏，注解+Jackson序列化期间脱敏，支持身份证/手机号/地址/邮箱/银行卡等策略 |
| **common-translation** | 数据翻译，注解+Jackson序列化动态翻译，支持映射翻译/直接翻译等模式 |
| **common-oss** | 对象存储，基于AWS S3协议，支持Minio/七牛/阿里OSS/腾讯COS等 |
| **common-excel** | Excel处理，基于FastExcel，支持自动合并、字典翻译、布局排列 |
| **common-log** | 操作日志记录，基于注解+AOP自动记录 |
| **common-ratelimiter** | 接口限流，基于Redis+Lua实现 |
| **common-idempotent** | 幂等控制，参考美团GTIS防重系统实现 |
| **common-web** | Web基础配置，XSS防护、全局异常处理、请求包装 |
| **common-doc** | SpringDoc接口文档配置 |
| **common-json** | Jackson序列化配置 |
| **common-mail** | 邮件发送封装 |
| **common-sms** | SMS4J短信融合，支持数十种短信厂家 |
| **common-social** | JustAuth第三方登录集成 |
| **common-sse** | SSE服务端推送，支持Token鉴权与分布式会话同步 |
| **common-websocket** | WebSocket通信，支持Token鉴权与分布式会话同步 |
| **common-job** | SnailJob客户端集成 |

### 3.3 ruoyi-modules — 业务模块

#### ruoyi-system (系统管理)

核心业务模块，包含 **151个Java文件**，涵盖：

- **用户管理**: `SysUserController` — 用户CRUD、导入导出、密码重置、头像上传
- **角色管理**: `SysRoleController` — 角色CRUD、权限分配、数据范围设置
- **菜单管理**: `SysMenuController` — 菜单CRUD、树结构构建
- **部门管理**: `SysDeptController` — 部门CRUD、树结构
- **岗位管理**: `SysPostController` — 岗位CRUD
- **字典管理**: `SysDictTypeController` / `SysDictDataController` — 字典类型与数据管理
- **参数管理**: `SysConfigController` — 系统参数配置
- **通知公告**: `SysNoticeController` — 公告发布管理
- **租户管理**: `SysTenantController` / `SysTenantPackageController` — 租户与套餐管理
- **客户端管理**: `SysClientController` — 对接客户端管理(PC/小程序等)
- **文件管理**: `SysOssController` / `SysOssConfigController` — 文件上传与存储配置
- **个人中心**: `SysProfileController` — 个人信息维护
- **社交绑定**: `SysSocialController` — 第三方登录绑定
- **监控管理**: `CacheController` / `SysUserOnlineController` / `SysLogininforController` / `SysOperlogController` — 缓存/在线用户/登录日志/操作日志

#### ruoyi-workflow (工作流)

基于 **Warm-Flow** 国产工作流引擎，包含 **79个Java文件**：

- **流程定义**: `FlwDefinitionController` — 流程设计、发布、版本管理
- **流程实例**: `FlwInstanceController` — 流程发起、取消、作废、终止
- **任务管理**: `FlwTaskController` — 审批、转办、委派、加减签、会签、或签、催办
- **流程分类**: `FlwCategoryController` — 流程分类管理
- **表达式管理**: `FlwSpelController` — SpEL表达式配置
- **演示案例**: `TestLeaveController` — 请假流程示例

支持功能：审批、转办、委派、加减签、会签、或签、票签、抄送等复杂审批场景。

#### ruoyi-generator (代码生成器)

基于Velocity模板引擎，支持：
- 多数据源代码生成
- 前后端CRUD代码一键生成 (Java/HTML/XML/SQL)
- 适配MyBatis-Plus与SpringDoc规范

#### ruoyi-job (任务调度)

基于SnailJob的任务调度业务模块，支持分布式任务、分片重试、DAG任务流等。

#### ruoyi-demo (功能演示)

提供框架各功能的实际使用案例，便于开发者参考学习。

### 3.4 ruoyi-extend — 扩展模块

| 模块 | 说明 |
|------|------|
| **ruoyi-monitor-admin** | 基于Spring Boot Admin的监控中心，实时监控服务状态、在线日志查看 |
| **ruoyi-snailjob-server** | SnailJob调度服务端，统一任务管理中心 |

## 4. 核心架构设计

### 4.1 认证授权流程

```
客户端请求
  │
  ▼
Web过滤器 (common-security)
  │
  ├─ 白名单路径 → 直接放行
  │
  ▼
Sa-Token鉴权 (common-satoken)
  │
  ├─ Token校验 (JWT格式)
  ├─ 登录状态检查
  ├─ 权限/角色注解校验 (@SaCheckPermission / @SaCheckRole)
  │
  ▼
多租户过滤 (common-tenant)
  │
  ├─ 从Token中提取租户ID
  ├─ MyBatis-Plus租户插件自动拼接SQL条件
  │
  ▼
数据权限过滤 (common-mybatis)
  │
  ├─ 基于MyBatis-Plus插件分析拼接SQL
  ├─ 支持部门/角色/自定义数据范围
  │
  ▼
业务Controller处理
```

### 4.2 多租户架构

```
┌──────────────────────────────────────┐
│            请求入口                    │
│  (Token中包含 tenantId 信息)          │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│       TenantLineHelperInterceptor    │
│  (MyBatis-Plus 多租户插件)            │
│  自动为SQL添加 tenant_id 条件         │
└──────────────┬───────────────────────┘
               │
    ┌──────────┼──────────┐
    ▼          ▼          ▼
 租户A数据    租户B数据    租户C数据
 (隔离存储于同一数据库)

排除表(不参与租户过滤):
  sys_menu, sys_tenant, sys_tenant_package,
  sys_role_dept, sys_role_menu, sys_user_post,
  sys_user_role, sys_client, sys_oss_config, flow_spel
```

### 4.3 数据权限体系

```
用户 → 角色 → 数据范围
              │
              ├─ 全部数据权限
              ├─ 自定义数据权限
              ├─ 本部门数据权限
              ├─ 本部门及以下数据权限
              ├─ 仅本人数据权限
              │
              ▼
      MyBatis-Plus DataPermissionInterceptor
      自动分析SQL并拼接过滤条件
```

### 4.4 安全体系

```
┌─ 接口传输加密 ─── 动态AES + RSA (每次请求秘钥不同)
│
├─ 数据加解密 ─── 注解 + MyBatis拦截器 (BASE64/AES/RSA/SM2/SM4)
│
├─ 数据脱敏 ─── 注解 + Jackson序列化 (身份证/手机号/地址/邮箱/银行卡)
│
├─ XSS防护 ─── 全局过滤器 + 可配置排除路径
│
├─ 幂等控制 ─── 参考美团GTIS防重系统 + Redis分布式锁
│
├─ 接口限流 ─── Redis + Lua脚本
│
├─ 分布式锁 ─── Lock4j + Redisson (超时30s/获取超时3s)
│
└─ 密码安全 ─── 最大错误5次 → 锁定10分钟
```

## 5. 关键技术实现

### 5.1 登录认证策略模式

采用 **策略模式** 实现多种登录方式，通过 `IAuthStrategy` 接口统一抽象：

```
IAuthStrategy (接口)
├── PasswordAuthStrategy   — 账号密码
├── SmsAuthStrategy        — 短信验证码
├── EmailAuthStrategy      — 邮箱验证码
├── SocialAuthStrategy     — 第三方社交 (微信/钉钉等)
└── XcxAuthStrategy        — 微信小程序
```

### 5.2 缓存体系

基于 Redisson 客户端，扩展 Spring Cache 注解：

- 支持设置 **过期时间**、**最大空闲时间**、**组最大长度**
- 支持 Redis 单机/哨兵/集群模式
- 缓存键命名规范: `模块名:业务名:标识`
- 内置缓存常量定义于 `CacheNames`

### 5.3 国际化支持

```
i18n/
├── messages.properties           # 默认
├── messages_zh_CN.properties     # 中文
└── messages_en_US.properties     # 英文
```

基于请求头 `Accept-Language` 动态返回不同语种文本。

### 5.4 多环境配置

| 环境 | Profile | 日志级别 | 说明 |
|------|---------|---------|------|
| 本地 | local | info | 本地开发 |
| 开发 | dev (默认) | info | 开发环境 |
| 生产 | prod | warn | 生产环境 |

### 5.5 数据库支持

原生支持多种数据库，可同时使用异构切换：

- MySQL
- Oracle
- PostgreSQL
- SQLServer
- 达梦、金仓等 (通过MyBatis-Plus扩展)

主键策略: **雪花ID** (`ASSIGN_ID`)，支持分库分表场景。

## 7. 设计亮点总结

1. **插件化模块设计**: 23个common子模块，职责单一，按需引入，解耦彻底
2. **多租户原生支持**: 基于MyBatis-Plus插件实现无感式数据隔离
3. **数据权限插件化**: 基于MyBatis-Plus插件自动分析拼接SQL，支持多种数据范围
4. **策略模式登录**: 统一接口抽象，支持5种登录方式灵活扩展
5. **注解驱动**: 加解密、脱敏、翻译、日志、限流、幂等等均通过注解实现，零侵入
6. **Jackson序列化扩展**: 脱敏与翻译在序列化期间完成，性能优异
7. **分布式全套件**: Redisson缓存+Lock4j分布式锁+SnailJob任务调度+幂等控制
8. **多数据库兼容**: 原生支持MySQL/Oracle/PostgreSQL/SQLServer及国产数据库
9. **接口传输加密**: 动态AES+RSA，每次请求秘钥不同，安全性高
10. **工作流集成**: 国产Warm-Flow引擎，支持复杂审批流程

## 10. 总结

RuoYi-Vue-Plus 是一个面向 **分布式集群与多租户** 场景的企业级后台管理系统。相比原版 RuoYi，在架构设计上进行了全面重写升级：

- **技术栈现代化**: Spring Boot 3.5 + JDK 17/21 + MyBatis-Plus + Sa-Token
- **架构解耦**: 插件化模块设计，23个通用子模块职责清晰
- **安全增强**: 传输加密、数据加解密、脱敏、XSS防护、限流、幂等全方位覆盖
